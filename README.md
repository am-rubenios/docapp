Docapp

iOS application developed as part of a technical assignment.

Overview

Docapp is an iOS application that demonstrates user data management, and interaction with remote services using modern Apple development frameworks.


Architecture

The project follows the MVVM (Model-View-ViewModel) pattern to ensure clear separation of concerns, maintainability, and scalability.

Notes

This project was created as part of a technical assignment and is intended to demonstrate practical iOS development skills, including networking, data persistence, and application architecture.
