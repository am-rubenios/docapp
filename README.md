Docapp

iOS application developed as part of a technical assignment.

Overview

Docapp is an iOS application that demonstrates user data management, authentication, and interaction with remote services using modern Apple development frameworks.

Tech Stack

* Swift
* SwiftUI
* MVVM Architecture
* Firebase (Authentication, Firestore, Storage)
* URLSession / Alamofire
* CoreData
* Keychain

Features

* User authentication
* Profile management
* Remote data fetching and storage
* Local data persistence
* Secure data handling

Architecture

The project follows the MVVM (Model-View-ViewModel) pattern to ensure clear separation of concerns, maintainability, and scalability.

Notes

This project was created as part of a technical assignment and is intended to demonstrate practical iOS development skills, including networking, data persistence, and application architecture.
